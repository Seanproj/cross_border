## 1. 디자인 토큰

| 토큰 | Light | 용도 |
|---|---|---|
| `background` | `#f7f8fa` | 페이지 배경 (오프화이트) |
| `surface` / `surface-muted` | `#ffffff` / `#f0f3f7` | 카드 / 보조 영역 |
| `border` | `#e1e6ee` | 카드 테두리 (그림자 대신 얇은 선) |
| `foreground` / `muted-foreground` | `#14213d` / `#5a6478` | 본문(네이비) / 보조 텍스트 |
| `primary` | `#2563eb` | 핵심 CTA, 링크 (화면당 CTA 1개 우선) |
| `success` / `warning` / `danger` | 그린 / 앰버 / 레드 | 완료 / 확인 필요·검토 전 / 오류 — 항상 아이콘+텍스트 병행 |
| `info-surface` | `#eaf1fe` | 추천(NBA) 카드 배경 |
| `radius-card` | 14px | 카드 모서리 |

다크 모드 값도 같은 이름으로 정의되어 있습니다. 본문 16px, 줄 간격 1.6.

## 2. 대시보드 (데스크톱)

```text
┌────────────┬──────────────────────────────────────────────────────────────┐
│ LOGO       │ 안녕하세요 · 베를린 이주 준비                       [프로필 ▾] │
│            ├──────────────┬──────────────┬──────────────┬────────────────┤
│ ▣ 대시보드  │ 전체 업무 n  │ 진행 중 n    │ 완료 n       │ 다음 공식 기한  │
│ ○ 프로필    │              │              │              │ (출처 있을 때만)│
│ ○ 체크리스트 ├──────────────┴───┬──────────┴──────────────┬───────────────┤
│ ○ 타임라인  │ 진행률 (도넛)      │ 다음 행동 추천 (NBA)     │ 다가오는 일정   │
│ ○ AI 어시스턴트│ 완료 / 제외 제외   │ 업무명 · 추천 이유        │ 날짜 · 업무명   │
│ ○ 평가 리포트 │                  │ 준비 서류 · 근거 출처 링크 │ [공식][목표] 구분│
│ ○ 설정      │                  │ [시작하기]  [나중에]      │               │
│            ├──────────────────┴─────────┬──────────────┴───────────────┤
│            │ 체크리스트 미리보기 (5개)    │ AI 질문하기 (입력창 + 최근 답변) │
│            ├────────────────────────────┴──────────────────────────────┤
│            │ 출처 상태: 검증됨 n · 검토 전 n · 재확인 필요 n │ 최신 평가 통과율 │
└────────────┴──────────────────────────────────────────────────────────────┘
```
모바일: 사이드바 → 상단 메뉴 버튼(drawer), 카드는 한 열. 순서: NBA → KPI → 일정 → 체크리스트 → AI.

빈 상태: 프로필이 없으면 KPI 대신 "상황을 알려주시면 체크리스트를 만들어 드려요 [시작하기]" 한 장만 표시.

## 5. AI 어시스턴트 / 평가 리포트
- 어시스턴트: 답변 위에 상태 배지(`답변됨`/`일부 근거`/`공식 확인 필요`/`범위 밖`), 주장마다 각주 번호 → 하단 출처 카드(위 상세 패널과 같은 컴포넌트). 하단 고정 고지: "일반 정보이며 법률 자문이 아닙니다."
- 공개 평가 리포트: 지표별 통과율 막대(자동/LLM 판정/사람 검토 구분), 버전 비교, 대표 실패 사례(예: `rag.conflict.korea_visa_free` 각주 오독)와 수정 내역.
