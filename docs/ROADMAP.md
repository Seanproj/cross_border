# 90-Day Roadmap — 10 hours/week

총 13주, 약 130시간. 매주 기본 배분은 구현 7h, AI 학습/실험 2h, 문서화/회고 1h입니다.

| 주차 | 시간 | 핵심 작업 | 산출물 | 완료 기준 |
|---|---:|---|---|---|
| 1 | 10h | 사용자 문제, 이주 시나리오, 30개 업무 수집 | PRD v1 | 핵심 사용자 여정과 범위 승인 |
| 2 | 10h | ERD, 화면 흐름, 디자인 토큰 | ERD + 와이어프레임 | 주요 엔티티와 화면 확정 |
| 3 | 10h | Next.js, Supabase, Auth, 프로필 | 작동 프로필 | 프로필 생성/수정/저장 |
| 4 | 10h | 업무 템플릿 및 출처 데이터 | Task DB | 검증 상태/출처 필드 포함 |
| 5 | 10h | 체크리스트, 상태 변경, 필터 | Checklist UI | CRUD 및 권한 테스트 통과 |
| 6 | 10h | 타임라인, 날짜, 의존성 표시 | Timeline UI | 날짜 미확정 상태 표현 |
| 7 | 10h | 프로필 자연어 추출, 구조화 출력 | Profile AI | 스키마 테스트 통과 |
| 8 | 10h | 공식 문서 수집/청킹/임베딩/RAG | RAG Guide | 답변 출처 표시 |
| 9 | 10h | Next Best Action 추천 | AI Planner | 추천 이유/조건/근거 반환 |
| 10 | 10h | 50개 평가 케이스 및 실패 분석 | Eval Report v1 | 중대 오류 수정 |
| 11 | 10h | UX 개선, 모바일, 보안, 배포 | Public Beta | 공개 URL 및 기본 흐름 동작 |
| 12 | 10h | README, 아키텍처, 데모 영상 | Portfolio Pack | 타인이 재현/이해 가능 |
| 13 | 10h | 피드백 반영, 릴리스, 회고 | v1.0 Launch | KPI 및 한계 공개 |

## 주간 루틴 예시
- 평일 세션 1: 2시간 — 구현
- 평일 세션 2: 2시간 — 구현/테스트
- 주말 세션: 5시간 — 핵심 기능 완성
- 주간 회고: 1시간 — AI 실험, 문서화, 다음 주 계획

## 우선순위 규칙
1. P0 사용자 핵심 흐름을 먼저 완성한다.
2. AI 기능은 실제 제품 흐름에 연결한다.
3. AI 평가와 근거 표시는 공개 포트폴리오의 차별점으로 확보한다.
4. P2 기능은 90일 내 구현하지 않는다.
5. 한 주가 밀리면 기능을 줄이고 시간을 늘리지 않는다.

## KPI
- 공개 웹앱 1개
- 검증 상태가 기록된 업무 템플릿 30~50개
- AI 기능 3개
- 평가 케이스 50개
- 핵심 평가 통과율 목표 90%
- 중대한 허위 법적 단정 0건
- 실제 사용 시나리오 10회 이상
- 기술 문서 및 2~3분 데모 1세트
