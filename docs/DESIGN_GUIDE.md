# Design Guide

## 1. 디자인 방향
- 제품 인상: 신뢰감, 차분함, 명확함, 국제적
- 스타일: Clean Minimal SaaS
- 기본 배경: 오프화이트/아주 옅은 쿨그레이
- 기본 텍스트: 네이비/차콜
- 포인트: 블루
- 상태: 완료=그린, 주의=앰버, 오류=레드
- 장식보다 정보 계층과 가독성을 우선합니다.

## 2. 주요 화면
1. Dashboard: 전체 업무 수, 진행률, 다음 행동, 다가오는 일정
2. Profile: 이주 상황과 개인 조건
3. Checklist: 카테고리, 상태, 우선순위, 출처
4. Timeline: 날짜와 선행 관계
5. AI Assistant: 질문/답변/출처 카드
6. Evaluation: 테스트 통과율, 실패 유형, 버전 비교
7. Settings: 국가/언어/개인정보 설정

## 3. Dashboard 레이아웃
- 좌측 고정 사이드바: Dashboard, Profile, Checklist, Timeline, AI Assistant, Evaluation
- 상단: 인사말, 목적지 국가, 프로필 메뉴
- 첫 행: 전체 업무 / 진행 중 / 완료 / 다음 마감
- 두 번째 행: 진행률 / Next Best Action / 다가오는 일정
- 세 번째 행: 체크리스트 미리보기 / 타임라인 미리보기 / AI 대화
- 하단: 출처 검증 상태와 AI Evaluation 요약

## 4. UI 규칙
- 카드 radius 12~16px, 얕은 그림자 또는 얇은 테두리
- 본문 텍스트 14~16px, 충분한 줄 간격
- 핵심 CTA는 화면당 1개를 우선
- 상태를 색상만으로 표현하지 말고 텍스트/아이콘 병행
- 빈 상태에는 다음 행동을 안내
- 모바일에서는 사이드바를 drawer로 전환하고 카드들을 단일 열로 배치

## 5. 이미지 레퍼런스 사용
프로젝트 루트의 `dashboard_mockup.png`를 시각적 참고 자료로 사용합니다.
이는 레이아웃/스타일 방향을 위한 컨셉 이미지이며, 이미지 안의 문구·수치·날짜·행정 내용은 사실 데이터로 사용하지 않습니다.

## 6. Claude Code용 디자인 지시
"dashboard_mockup.png를 시각적 방향으로 참고하되, 이미지의 텍스트와 숫자를 그대로 복사하지 말고 실제 앱 데이터와 컴포넌트로 재구성하라. 접근성, 반응형, 로딩/빈/오류 상태를 포함하고, 불필요한 장식보다 정보 가독성을 우선하라."
